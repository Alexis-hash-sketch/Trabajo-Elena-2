La web que he elegido

He elegido Nike porque es una tienda online conocida donde se pueden consultar zapatillas, ropa y otros productos deportivos.

Glosario

Término Definición con mis palabras Ejemplo en mi web
Cliente Es el programa o dispositivo que solicita información o servicios a un servidor. El navegador solicita a Nike las páginas de zapatillas y ropa.
Servidor Es el equipo que recibe las solicitudes y envía los datos necesarios. Los servidores de Nike envían al navegador el contenido de la tienda online.
Servidor web Es el software que recibe peticiones HTTP/HTTPS y entrega páginas o recursos. Cuando abro nike.com, el servidor web devuelve la página de inicio.
Apache Es un software de servidor web que puede alojar sitios y responder a peticiones; no significa que todas las webs lo utilicen. Nike necesita un servidor web para mostrar su tienda, aunque no se puede asegurar que use Apache sin comprobarlo.
URL Es la dirección completa que permite localizar un recurso en internet. https://www.nike.com/ es una URL de la tienda de Nike.
Protocolo Es un conjunto de reglas que permite que los equipos se comuniquen. La dirección de Nike empieza por HTTPS, que indica el protocolo seguro usado.
Dominio Es el nombre legible que identifica un sitio en internet. El dominio de la web es nike.com.
Ruta Es la parte de una URL que indica qué página o recurso se quiere abrir. En https://www.nike.com/w/..., la parte que comienza por /w/ sería una ruta de la web.
Dirección IP Es un número que identifica un dispositivo o servidor dentro de una red. El DNS traduce nike.com a una dirección IP; la dirección concreta puede variar.
DNS Es el sistema que convierte nombres de dominio en direcciones IP. Al entrar en nike.com, el DNS ayuda al navegador a encontrar el servidor correspondiente.
HTTP Es un protocolo para intercambiar solicitudes y respuestas web; por sí solo no cifra la comunicación. La tienda utiliza HTTPS, una versión protegida de HTTP.
HTTPS Es HTTP protegido mediante cifrado TLS, que ayuda a proteger los datos durante la conexión. La URL de Nike empieza por https:// y el navegador puede mostrar un candado.
Puerto Es un número que identifica el servicio de red al que se conecta un programa. HTTPS suele usar el puerto 443 para conectarse a una web.
Petición Es el mensaje que el navegador envía al servidor para pedir una página o un recurso. Al abrir nike.com, el navegador envía una petición para obtener la página.
Respuesta Es el mensaje que el servidor devuelve después de recibir una petición. Nike responde enviando HTML, estilos, imágenes y otros recursos.
Código de estado Es un número que informa del resultado de una petición HTTP, por ejemplo 200 o 404. En las herramientas de desarrollador, una petición correcta puede aparecer con estado 200.
Web estática Es una página cuyo contenido se entrega como archivos ya preparados, sin generarlo de nuevo para cada usuario. Una imagen o un archivo CSS de la web puede servirse como recurso estático.
Web dinámica Es una web que adapta o genera contenido según datos, acciones o la sesión del usuario. La tienda Nike puede mostrar productos, tallas y disponibilidad según la selección o región.
PHP Es un lenguaje de programación que puede ejecutarse en el servidor para generar páginas web. No se puede afirmar que Nike use PHP sin inspeccionar su tecnología; es un ejemplo de lenguaje del lado servidor.
Base de datos Es un sistema organizado para guardar y consultar información. Una tienda online suele necesitar datos de productos, tallas y stock; no se conoce la base de datos concreta de Nike.
LAMP Es una combinación de Linux, Apache, MySQL/MariaDB y PHP usada para alojar aplicaciones web. LAMP es una posible arquitectura web, pero no se debe asumir que Nike la utiliza.
JSON Es un formato de texto que organiza datos en pares clave-valor y listas. Una web puede intercambiar datos de productos en JSON mediante peticiones Fetch/XHR.
XML Es un formato de texto que organiza información mediante etiquetas. XML puede utilizarse para feeds o datos estructurados; no se asegura que Nike lo use en una función concreta.
